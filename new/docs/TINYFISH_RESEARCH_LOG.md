# TinyFish research log

Date: 2026-10-24

TinyFish Search was used server-side to verify the frontend mapping direction. It returned the MapLibre GL JS documentation, its 3D-building example, and the MapLibre GL JS repository. The frontend now uses MapLibre rather than the inherited Leaflet dependency, which aligns with the project architecture.

- [MapLibre GL JS documentation](https://www.maplibre.org/maplibre-gl-js/docs/)
- [MapLibre 3D buildings example](https://www.maplibre.org/maplibre-gl-js/docs/examples/display-buildings-in-3d/)
- [MapLibre GL JS repository](https://github.com/maplibre/maplibre-gl-js)

Research is not accessibility evidence. Campus geometry, routes, and lift status remain unknown until supplied by their authoritative owners/sources.
