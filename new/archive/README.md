# Archive

## `web-maplibre-preview/`
An earlier frontend prototype (React 18 + MapLibre, IIIT Delhi demo area). It calls `GET /api/places` and `POST /api/route` with `{ startId, destinationId, mode }`, which no backend in this repository implements, so it cannot run end-to-end today. It is kept for its design work and as a reference if the FastAPI routing API is built. It also contains the original `push_to_github.ps1`, which refers to paths on the original author's machine.

Not part of CI or the Docker setup.
